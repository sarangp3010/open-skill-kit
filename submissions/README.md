# Pending skill proposals

Proposed packages belong at submissions/{canonical-sector}/{skill-slug}/. Include the complete SKILL.md package and a submission.json request generated by the browser editor. This directory is validated but **never indexed, bundled or copied into public website assets**. Empty proposals and unapproved browser content do not become catalog entries.

Open a GitHub pull request for review. Do not move a package into skills/ or change publication decisions yourself. An authorized maintainer reviews the exact content, accepts/promotes it, records approval and merges through the documented review gates. See [moderation policy](../docs/moderated-submissions.md).
