# Using this authoring template

Copy this folder to skills/personal-productivity/example-skill to try it locally, or rename it for your own sector/skill. It is outside the active catalog until copied. Replace sample task content, title, author and provenance before contributing. Keep name, folder, metadata ID/sector/slug and tests/cases.json skillId consistent.

The two example pairs and cases are authoring illustrations, not executed tests. There are deliberately no completed platform results. Do not invent testing dates or records. Add compatiblePlatforms to metadata only as a clearly labeled compatibility declaration; it does not establish actual testing.

Run the repository validation and quality CLI before requesting review. A full structural score on this template is not evidence that your rewritten workflow is correct or safe.
