## Remaining issues and owner decisions

1. **Upstream license provenance exception:** react-remove-scroll-bar@2.3.8 declares MIT but omits its license text. Its npm gitHead returned 404 upstream. The retained notice comes verbatim from available pinned upstream source declaring 2.3.7/MIT, with that limitation embedded in docs and distribution notices. Hash/license mismatches fail the build. Resolve or accept this provenance issue before public redistribution; exact-release source verification is not claimed. See [licensing details](licensing.md).
2. **Remote settings/contact routes:** repository visibility, private vulnerability reporting, a usable confidential conduct/security contact, fork approval/token/secret settings, environment protections and free-tier spending limits were not changed or remotely verified. CODEOWNERS is review routing, not enforcement by itself. No paid protection feature is required or enabled. See [readiness checklist](community-readiness.md).
3. **Pre-existing case-only status filenames:** docs/IMPLEMENTATION_STATUS.md and docs/implementation-status.md are both tracked. They remain intact to preserve history/links; a link-preserving naming migration is needed before promising case-insensitive filesystem support. Windows/case-insensitive checkouts are not validated here.
4. **Independent review and hosted evidence:** all skills remain drafts; actual attribution identity review, professional review, live agent compatibility/effectiveness, hosted CI execution and public-site indexing are not performed or inferred from local tests.

Static metadata/noscript output is not full React SSR, search-engine ranking assurance or complete assistive-technology certification. Project-path robots.txt cannot control an entire GitHub Pages origin. These are documented static-host limits, not hidden service dependencies.

Everything remains local and uncommitted. HEAD remains 8bb0057. No commit, push, PR, publication, deployment, visibility change or hosted workflow execution occurred.
