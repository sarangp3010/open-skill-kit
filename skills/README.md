# Open Skill Kit skill library

Portable Markdown workflows grouped by sector. All active packages are **authoring drafts pending independent human review**; examples are authored illustrations, not executed assistant runs. Deterministic package checks do not prove professional correctness or model behavior. Drafts remain excluded from npm publication.
